## 🚢 What I Do

I work in **maritime container shipping operations**, translating raw booking data and vessel capacity into actionable decisions — fast.

My day-to-day involves:

- 📦 **Capacity Planning** — TEU/weight/reefer analysis, overbooking control, shortfall risk
- 🛳️ **Vessel Operations** — voyage tracking, transshipment routing, load list management
- 📊 **BI Reporting** — automated dashboards in Power BI replacing hours of manual Excel work
- 🐍 **Python Automation** — scripts that pull SAP exports, flag anomalies, and generate reports automatically
